## 1. Methodology

The 8.3MB WXR file was parsed with Python's `xml.etree.ElementTree` after
one data-quality fix (below). Every `<item>` was classified by
`<wp:post_type>` / `<wp:status>`:

| post_type : status | count |
|---|---|
| `page:publish` | **37** |
| `post:publish` | **53** |
| `page:draft` | 1 (ignored, unpublished) |
| `post:draft` | 1 (ignored, unpublished) |
| `attachment:inherit` | 136 (ignored, media) |
| `nav_menu_item:publish` | 50 (ignored, navigation) |
| `elementor_library:publish/trash` | 23 (ignored, page-builder templates) |
| `elementor-hf:publish` | 2 (ignored, header/footer templates) |
| `custom_css:publish` | 2 (ignored, theme CSS) |
| `wp_global_styles:publish` | 2 (ignored, theme styling) |
| `wp_navigation:publish` | 5 (ignored, navigation) |

**37 + 53 = 90 published URLs** — matches the count stated in the task.

For each of the 90, extracted: title, slug, live URL, publish/modified
date, categories, plain-text word count (HTML/scripts stripped), and SEO
plugin metadata. The site runs **both Yoast and RankMath** postmeta
(RankMath's `rank_math_*` fields are populated and current; Yoast's
`_yoast_wpseo_*` fields appear to be from a earlier, now-inactive plugin —
RankMath was preferred wherever both existed). Extracted specifically:
`rank_math_canonical_url`, `rank_math_robots` (PHP-serialized), `rank_math_title`,
`rank_math_description`, `rank_math_focus_keyword`. No author email
addresses or other private author fields are reproduced anywhere in this
report or in the data files this session generated.

**One data-quality issue in the export itself, corrected before parsing:**
a single stray NUL byte (0x00) at line 12928, inside a `content:` CSS
property in a theme/Elementor CSS block (`content: "<NUL>0bb";` — almost
certainly a mangled `\00bb` escape for a » character). This is template
CSS, not page content, and irrelevant to the migration decisions below. It
was stripped from a working copy used only for parsing; the original
uploaded file was not modified.

**Cross-referenced against:** the 41 pages under `site/`, `site/sitemap.xml`
(41 URLs), `infra/redirects.json` (14 redirects), and the 45-URL inventory
in `scripts/phase3b-old-url-test.js`.
